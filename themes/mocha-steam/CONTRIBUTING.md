# Contributing to Mocha Steam

Thanks for helping. Steam changes its pages often, so reports from other PCs matter.

## Ways to help

- Report a page or menu that looks wrong after a Steam update, with a screenshot
- Send fixes for pages the theme does not cover yet
- Test the theme options you use and say which ones break

## Getting set up

1. Install [Millennium](https://docs.steambrew.app/users/getting-started/installation).
2. Clone this repo into `Steam\millennium\themes\MochaSteam`.
3. Pick Mocha Steam in Millennium's Themes tab. CSS changes show after a reload of the theme.

## Checks before a pull request

- Check your change in Library, Store and a menu, at full width and in a narrow window
- Keep colours on the Mocha variables in `src/css/regular.css`
- Include your Steam and Millennium versions

## Where to submit

Open issues and pull requests in this repository.
