# Contributing

Thanks for helping MochaSteam. It is an installable Steam theme, so contributions are mostly CSS and installer fixes.

## Ways to help

- Report Steam client updates that break the theme
- Send CSS fixes and installer improvements
- Share screenshots of anything that looks off

## Getting set up

Apply the theme to a test Steam install with:

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Apply -Configure
```

## Checks before a pull request

- Screenshot before and after your change
- Re-run the installer after a Steam restart to confirm it still applies

## Where to submit

Open issues and pull requests in this repository.
